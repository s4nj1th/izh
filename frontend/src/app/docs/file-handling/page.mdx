# File Handling

VaraiX can load CSV files into arrays with the `csv()` helper. The helper returns an array of rows, so you can pass its result directly to `data:` or assign it to a variable first.

## Basic usage

```vix
chart: line
title: Revenue From CSV

data: csv("revenue.csv")
```

You can also store the result in a variable:

```vix
rows = csv("revenue.csv")
data: rows
```

## Path resolution

When you run VaraiX from the CLI, relative CSV paths are resolved from the location of the `.vix` file. That makes it easy to keep a chart and its data file in the same folder.

Absolute paths also work if you want to point at a file elsewhere on disk.

## CSV parsing rules

- Every CSV row is included in the result, including the first row if your file has headers.
- Empty cells become `null`.
- Numeric cells are parsed as numbers when possible.
- Other values stay as strings.

## Browser editor note

The browser-based editor cannot read local files, so CSV loading is only available when the chart runs from the CLI or another local file-backed environment.

## Good fit

Use `csv()` when:

- your data already lives in a CSV file
- you want to keep the `.vix` file small
- you want to reuse the same dataset across multiple charts

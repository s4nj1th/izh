# Arrays, Ranges & Comprehensions

VizLang supports fixed-size arrays that are evaluated at parse time. They are useful when you want to generate data cleanly without repeating every row by hand.

## Explicit lists

Use explicit lists when the values are short and already known.

```vizl
values = [1, 2, 3, 4]
labels = ["Jan", "Feb", "Mar"]
```

## Inclusive ranges

Ranges create inclusive integer sequences.

```vizl
years = [2018..2022]  # => [2018, 2019, 2020, 2021, 2022]
```

Use ranges to generate labels, counts, or year spans without writing each element manually.

Another range example:

```vizl
months = [1..12]
```

## Simple comprehensions

Comprehensions evaluate an expression for each value in a range.

```vizl
evens = [i * 2 for i in 1..5]  # => [2,4,6,8,10]
```

This is a good fit for synthetic data, derived values, and compact examples.

You can use the result to build short generated tables:

```vizl
offsets = [i + 10 for i in 1..5]
```

## Nested arrays (array-of-pairs)

Arrays can contain arrays. The most common use is a table of x/y pairs.

Other useful shapes:

```vizl
labels = [["Q1", "north"], ["Q2", "south"]]
```

```vizl
matrix = [[1, 2], [3, 4], [5, 6]]
```

```vizl
myData = [["Jan", 10], ["Feb", null], ["Mar", 20]]
data: myData
```

## Typed arrays

You can declare typed arrays when you want the element type to be explicit.

```vizl
int[] years = [2018..2022]
float[] measurements = [1.0, 2.5, 3.75]
string[] names = ["A", "B", "C"]
```

The parser coerces elements at parse time, which keeps the result deterministic and easy to reason about.

Typed arrays are especially useful when you want the file to document the intended element type at a glance.

## Example

```vizl
chart: bar
title: Yearly Counts

years = [2018..2022]
counts = [10, 20, 30, 25, 35]
data: [[2018, 10], [2019, 20], [2020, 30], [2021, 25], [2022, 35]]
```

## Compact pattern

```vizl
chart: line
title: Generated Values

values = [i * 3 for i in 1..8]
data: [[1, 3], [2, 6], [3, 9], [4, 12], [5, 15], [6, 18], [7, 21], [8, 24]]
```

## When to use arrays

- use lists for short fixed values
- use ranges for inclusive sequences
- use comprehensions for generated values
- use nested arrays for chart data
- use typed arrays when you want explicit scalar types

## Combining arrays

The `combine()` function pairs elements from two arrays into a new array of pairs. This is useful when you have separate arrays for x and y values that you want to merge into chart data.

```vizl
xs = [1, 2, 3, 4, 5]
ys = [10, 20, 30, 40, 50]

pairs = combine(xs, ys)
# => [[1, 10], [2, 20], [3, 30], [4, 40], [5, 50]]
```

### Real-world example

Suppose you have temperature readings and humidity measurements for the same time periods:

```vizl
chart: scatter
title: Temperature vs Humidity

x: temperature (°C)
y: humidity (%)

temps = [15, 18, 20, 22, 25, 28, 30, 32]
humidity = [45, 52, 58, 65, 72, 78, 82, 88]

data: combine(temps, humidity)
```

If the arrays have different lengths, `combine()` creates pairs up to the longest array length. For example:

```vizl
a = [1, 2, 3]
b = [10, 20]

result = combine(a, b)
# => [[1, 10], [2, 20], [3]]
```

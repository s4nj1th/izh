# Colors & Palettes

VizLang supports color palettes to control the appearance of charts. A palette is just an array of CSS color strings.

## Syntax

Inline palette:

```vizl
colors: ["red", "#ff0000", "rgb(0,128,255)"]
```

Named palette variable:

```vizl
palette = ["#111111", "#222222", "#333333"]
colors: palette
```

## What the renderer does

- `line` uses the first color for the line stroke.
- `bar` cycles through the palette per bar.
- `scatter` cycles through the palette per point.
- `pie` uses the palette per slice and falls back to the default palette when needed.

## Examples

Single color for a simple line:

```vizl
chart: line
colors: ["#4a90d9"]
myData = [["A", 10], ["B", 20], ["C", 15]]
data: myData
```

Palette for a pie chart:

```vizl
chart: pie
colors: ["#4a90d9", "#f06292", "grey", "#a1887f"]
myData = [["Linux", 72], ["Windows", 15], ["MacOS", 8], ["Other", 5]]

data: myData
```

## Tips

- Mix named colors, hex values, and `rgb()` or `hsl()` values freely.
- Provide at least as many colors as categories if you want stable categorical coloring.
- The renderer passes color strings directly into SVG attributes, so browser color parsing rules apply.

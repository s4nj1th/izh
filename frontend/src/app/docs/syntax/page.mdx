# Basic Syntax

varaiX uses a key-value structure for properties and a comma-separated format for data.

## Properties

Properties are defined at the top of your file using the `key: value` format.

```vizl
chart: bar
title: "My Awesome Chart"
x: "Category"
y: "Value"
```

### Key Properties

| Key     | Description                                          |
| ------- | ---------------------------------------------------- |
| `chart` | The type of chart (`line`, `bar`, `scatter`, `pie`). |
| `title` | The main heading of the chart.                       |
| `x`     | Label for the horizontal axis.                       |
| `y`     | Label for the vertical axis.                         |

## Data Block

The `data:` keyword marks the beginning of your data points. Each row below it should follow the `x, y` format.

```vizl
data:
"Jan", 100
"Feb", 150
"Mar", 125
```

> **Note**: Labels in the data block should be wrapped in double quotes (e.g., `"January"`) to distinguish them from variables.

## Arrays, Nulls & Colors (summary)

varaiX supports inline arrays and array-of-pairs which can be used as `data:` values. You can also set a `null_fill` policy and provide a color palette.

- Inline array-of-pairs:

```vizl
myData = [["Q1", 340], ["Q2", 520]]
data: myData
```

- `null_fill:` strategies: `zero`, `mean`, `prev`, `next`, `skip`.

```vizl
null_fill: mean
myData = [["Jan", 10], ["Feb", null], ["Mar", 20]]
```

- Colors palette:

```vizl
colors: ["red", "#00f", "rgb(0,128,255)"]
```

These features are documented in more detail in the Arrays and Colors pages in the Docs section.

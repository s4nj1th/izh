# Introduction

varaiX is a minimal chart description language designed for speed, clarity, and ease of use. It renders clean, professional SVGs instantly in your browser.

## Why varaiX?

Most charting libraries are either too complex or too rigid. varaiX strikes a balance by providing:

- **Deterministic Rendering**: The same code always produces the same SVG.
- **LLM-Friendly**: Simple syntax that AI models can easily generate and understand.
- **No Friction**: Write code, see chart. No configuration files or complex APIs.

## Getting Started

To create your first chart, head over to the [Editor](/editor) and choose an example from the dropdown menu.

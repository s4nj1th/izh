# Introduction

VaraiX is a small chart description language for people who want to describe a chart without building a full charting app. A `.vix` file is readable by humans, predictable for tools, and compact enough to generate from an LLM or a script.

The language is designed around a simple idea: write a few lines of text, render one chart, and get the same SVG every time.

## Why VaraiX?

VaraiX is useful when you want:

- **Deterministic output** so a chart definition always renders the same way.
- **Low ceremony** so the file stays short and easy to read.
- **LLM-friendly syntax** so generated chart specs are easy to validate and edit.
- **SVG output** that works in browsers, docs, slides, and static sites.

It fits especially well when you already know the shape of the chart and want a compact format instead of a large charting API.

## Quick Start

```vizl
chart: line
title: Monthly Revenue

myData = [["Jan", 12], ["Feb", 19], ["Mar", 15], ["Apr", 22]]
data: myData
```

That file defines one chart, gives it a title, and passes an inline array of pairs as the dataset.

## Common uses

- quick charts generated from scripts or AI output
- lightweight documentation examples
- data previews and internal dashboards
- SVG assets for blogs, reports, and slides

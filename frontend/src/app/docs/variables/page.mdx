# Variables, Expressions & Types

Variables are evaluated at parse time and can be used in chart properties and data rows. They keep files DRY and make formulas explicit.

## Assignment syntax

Basic assignment:

```vizl
name = EXPRESSION
```

Optional typed forms (coerce/declare intent):

```vizl
int count = 10
float ratio = 1.25
string label = "Q1"
int[] values = [10, 20, 30]
```

Typed scalar and array declarations coerce elements at parse time and produce clearer error messages when types mismatch.

## Supported operators and precedence

- Multiplication and division (`*`, `/`) have higher precedence than addition and subtraction (`+`, `-`).
- Parentheses override precedence.
- `+` is overloaded for numbers and strings (string concatenation).

Examples:

```vizl
revenue = (base + bonus) * 1.1
title = "Revenue " + year
```

## Using variables in data rows and properties

Variables may be referenced directly in `data:` rows and in property values. The parser substitutes their evaluated value.

```vizl
base = 100
increment = 25
data:
"Q1", base
"Q2", base + increment
```

## Arrays and combining arrays

Arrays can be assigned to variables and used to build inline data. Use `combine()` to pair two arrays into an array-of-pairs:

```vizl
xs = [1, 2, 3]
ys = [10, 20, 30]
data: combine(xs, ys)  # => [[1, 10], [2, 20], [3, 30]]
```

If arrays differ in length, `combine()` will produce pairs up to the longer array, leaving single-element arrays for missing counterparts (see Arrays docs for behavior details).

## Common pitfalls and error messages

- Undefined variable: referenced a name that has not been assigned. Define variables before use.
- Type mismatch: when assigning to a typed declaration, the parser will coerce where possible or raise an error for incompatible types.
- Division by zero will not be caught at parse-time if it depends on runtime data, but numeric expressions are evaluated at parse time for literals/variables.

## Practical examples

1. Generate labels and values programmatically:

```vizl
chart: bar
months = ["Jan", "Feb", "Mar"]
values = [10, 20, 30]
data: combine(months, values)
```

2. Build a title from parts:

```vizl
year = 2026
title: "Forecast " + year
```

3. Typed arrays for clear intent:

```vizl
int[] years = [2018..2022]
float[] readings = [1.2, 1.5, 2.0]
```

## Tips

- Keep variable assignments grouped near the top so readers can quickly find configurable values.
- Use descriptive names for intermediate variables to make formulas self-documenting.

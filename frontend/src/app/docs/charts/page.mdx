# Chart Types

VizLang currently supports four core chart types.

## Bar Chart
Best for comparing discrete categories.
```vizl
chart: bar
```

## Line Chart
Ideal for showing trends over time.
```vizl
chart: line
```

## Scatter Plot
Used to visualize relationships between two numerical variables.
```vizl
chart: scatter
```

## Pie Chart
Perfect for showing proportions of a whole.
```vizl
chart: pie
```

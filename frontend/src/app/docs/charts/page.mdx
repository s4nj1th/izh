# Chart Types and Data Shapes

VaraiX currently supports the following core chart types. The same top-level file shape is used for all charts; what changes is the expected data shape and how the renderer interprets values.

### 1) Bar chart

Purpose: compare categorical values. Each data row should be `[category, value]` where `category` is a string and `value` is numeric.

```vizl
chart: bar
title: Quarterly Sales
data: [["Q1", 120], ["Q2", 150], ["Q3", 170], ["Q4", 200]]
```

When using block data, the same shape applies:

```vizl
data:
"Q1", 120
"Q2", 150
```

### 2) Line chart

Purpose: show trends over an ordered X axis (time or numeric). `x` can be a string label or numeric value; `y` must be numeric. Line charts connect points in X-order.

```vizl
chart: line
title: Monthly Revenue
data: [["Jan", 12], ["Feb", 19], ["Mar", 15], ["Apr", 22]]
```

If your X values are numeric (dates converted to numbers, epoch seconds, etc.), the line will be positioned proportionally.

### 3) Scatter plot

Purpose: compare two numeric variables. For scatter plots, both elements of each pair should be numeric: `[x, y]`.

```vizl
chart: scatter
title: Height vs Weight
data: [[155, 52], [160, 58], [165, 62], [170, 68]]
```

Tip: Use `int[]`/`float[]` arrays and `combine()` for pairing two separate numeric arrays into scatter points.

### 4) Pie chart

Purpose: show parts of a whole. Each pair is `[label, value]` where `label` is a string and `value` is numeric and non-negative.

```vizl
chart: pie
title: Server Operating Systems
data: [["Linux", 72], ["Windows", 10], ["macOS", 8], ["Other", 6]]
```

Notes on pie charts:

- Keep slices to a reasonable number (6–8) for legibility.
- Values must sum to any positive total; renderer uses relative proportions.

## Shared rendering behaviors

- `colors:` accepts an array of CSS color strings. For `bar`/`scatter`/`pie`, the palette is applied per category/point/slice. For `line`, the first color is used for the line stroke.
- `null` values in the Y position are handled according to `null_fill` (see Nulls page).
- The renderer treats array-of-pairs uniformly; ensure your data format matches the chart semantics above.

## Advanced examples

1. Using `combine()` to prepare scatter data from two arrays:

```vizl
int[] xs = [1, 2, 3, 4]
int[] ys = [10, 20, 30, 40]
data: combine(xs, ys)
```

2. Typing arrays to document intent and coerce values:

```vizl
string[] months = ["Jan", "Feb"]
int[] values = [10, 20]
data: combine(months, values)
```

Choose the chart type based on the semantic shape of your data and the question you want the visualization to answer.
